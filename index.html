Customer kinematic envelope (KE)

Right half (Y ≥ 0) in mm, from the top centre clockwise down the side, as in the customer drawing. n_up is the last point of the car-body (upper) envelope: the notch below it (solebar / collector shoe) is excluded from the car-body check. Paste Y/Z columns from Excel into the table.

Track alignment

One row per element (Tangent / Transition / Circular) in increasing chainage, no gaps. R 0 = infinite; in a transition the curvature and cant change linearly from start to end. Rv > 0 crest, < 0 sag.
