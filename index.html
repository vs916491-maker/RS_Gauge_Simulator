Car types

One column per car type

Body length = bogie centre distance a + both overhangs. Bogie types are defined on the Car body & Bogie tab.

Bogie inputs

One column per bogie type

Lateral plays are each side. w is the secondary lateral displacement up to the hard stop (free play + bump stop deflection). Vertical values are positive in the direction stated (deflection downwards, rebound and over-inflation upwards).

Car body inputs

One column per car type (follows the Train Configuration tab)

Flexibility coefficient s and roll centre height hc from the suspension calculation or the static sway test. Random allowances (tolerances, dynamic oscillation) are combined by RSS or linearly, chosen in the simulation tabs.

Customer kinematic envelope (KE)

Right half (Y ≥ 0) in mm, from the top centre round the outside down to rail level. Several KEs can be kept (ballasted, ballastless, tunnel…). Paste Y/Z columns straight from Excel into the table.

Structure gauge / SOD

Same layout. Used by the dynamic simulation; each track segment picks its SOD.

Rolling stock static profiles

Car body outline, underframe equipment, bogie frame, axle-mounted items. The mounting level decides which movements apply: body = all, bogie = primary only, axle = unsprung (see Method §4.9).

Preview against the customer KE

The static profile normally sits well inside the KE: the gap is what the movements use up. The check itself is the Static Simulation.

Track parameters (whole line)

Track alignment

One row per element in increasing chainage. R = 0 for tangent, Rv > 0 crest / < 0 sag / 0 none. Transition curves: enter as short constant steps. Paste rows from Excel into the table.

Alignment against chainage

Static simulation — Phase 2

Conditions to be set here (Method §8): method (Metro SOD-style / EN 15273-2), customer KE, track condition (tangent or a design curve with cant and cant deficiency / excess), load conditions (tare / laden), suspension conditions (inflated / deflated), sections (car end, bogie centre, mid-car, user x), combination rule (RSS / linear) and safety margin, then Run static simulation.

Static results — Phase 2

Our KE against the customer KE, the maximum static profile against the RS profile, clearance at every point, governing case and the term-by-term displacement build-up, with graphs.

Dynamic simulation — Phase 3

Conditions to be set here (Method §9): chainage range, speed rule (line speed / Vmax / user), load and suspension conditions, sections, combination rule, SOD frame, then Run dynamic simulation along the Track Data.

Dynamic results — Phase 3

Minimum clearance against chainage (lateral, vertical, to each SOD item), a chainage selector showing the cross-section at that point (SOD, our KE, static profile) and the list of locations below the required clearance.
